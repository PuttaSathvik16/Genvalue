# GenValue — Video Script · Part 1 (0–10s)

**Tone:** Clean, confident, modern SaaS  
**Format:** Voiceover + on-screen text + UI motion  
**Cast:** None — no faces, no actors, no characters  
**Length:** ~10 seconds  
**Focus:** Core idea + problem  
**Rule:** Mention GenValue only — do not name or show other AI tools/brands.

---

## Shot list + voiceover

| Time | Visual (on screen) | Voiceover |
|------|--------------------|-----------|
| **0–3s** | Dark→cream brand open. Logo marks. Kinetic type: *Too many AI tools. Not enough judgment.* | “AI tools keep multiplying.” |
| **3–6s** | Abstract UI chaos: many blank tool tiles blur and collide → one clear path sharpens. Text: *Which tool for which task?* | “But choosing the right one for each task is still the hard part.” |
| **6–10s** | GenValue product UI settles in: clean dashboard / syllabus rail. Text: *GenValue teaches judgment.* | “GenValue teaches judgment — a practical system to pick, prompt, and ship with AI.” |
